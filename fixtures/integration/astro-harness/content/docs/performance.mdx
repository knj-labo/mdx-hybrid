## What to watch

- **Cold-start penalty**: NAPI bindings incur an upfront cost; measure with multiple runs.
- **I/O pressure**: Streaming rewrites keep memory stable even when docs exceed 1MB.
- **WASM parity**: The same harness can target `markflow-wasm` for edge runtimes.
