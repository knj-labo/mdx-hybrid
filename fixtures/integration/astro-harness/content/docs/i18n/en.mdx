# English Locale

The Astro docs site renders multiple locales from the same Markdown source. This page exists to ensure Markflow preserves locale-specific frontmatter.

- Locale: `en`
- Direction: `ltr`

> Translation pipelines often depend on consistent heading IDs. Markflow reuses the same slug generator as markdown-rs, so IDs remain deterministic.
